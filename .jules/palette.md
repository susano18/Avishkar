## 2025-05-15 - Output Panel Copy Feedback
**Learning:** For async copy operations, provide immediate visual feedback by toggling the button icon (e.g., from `Copy` to `Check`) and text for a short duration (e.g., 2 seconds) to confirm the action succeeded.
**Action:** Always implement a transient "success" state for copy-to-clipboard buttons to improve user confidence without cluttering the UI permanently.

# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-14 - Consistency in Destructive Actions
**Learning:** Inconsistent UI patterns for destructive actions (like deletion) can lead to user anxiety and accidental data loss. Using a confirmed pattern (like `AlertDialog`) across all list views (Library and History) provides a safer, more predictable experience.
**Action:** Always implement confirmation dialogs for destructive actions, even if they seem "minor", to maintain UX consistency and prevent accidental loss.
